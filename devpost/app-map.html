Application Map, Architecture & Technical Specifications (Current MVP)

1. Application Purpose & High-Level Architecture

Your friend LXNORO is a lightweight personal digital companion and Time Engine designed to connect long-range personal planning horizons (Daily, Weekly, Monthly, Yearly, Five-Year) with timely, actionable daily moments. The current runnable MVP is implemented in Python using Streamlit (streamlit_app.py) backed by local SQLite storage.

Streamlit MVP App (streamlit_app.py)

Provides the primary runnable interface for multi-horizon navigation, activity and routine management, precise date-aware recurrence filtering, local SQLite data persistence, and JSON backup export/restore.

Foundation & Roadmap Architecture (src/ & server/)

Modular TypeScript/React frontend and Fastify/SQLite backend codebases representing the broader architecture roadmap for shared booking, weather proxy, and notification services.

2. Actual Screens & Major UI Areas

  • Top Header & Live Clock: Displays brand identity and a real-time updating browser clock.
  • Planning Horizons Selector: Five interactive navigation buttons for Daily, Weekly, Monthly, Yearly, and Five-Year planning views.
  • Scheduled Tasks & Activities Panel: Displays filtered, chronologically ordered tasks and routines for the active horizon, with inline editing and deletion.
  • Activity & Element Grid: 16 quick starter elements that can be scheduled instantly into the active horizon.
  • Sidebar Custom Task & Backup Panel: Form to schedule custom tasks/routines and export/import JSON database backups.

3. Core User Flows

[Personal Time Planning Flow] [Launch Streamlit MVP] ---> [Select Horizon (Daily/Weekly/Monthly/Yearly/Five-Year)] ---> [Schedule from Starter Grid or Add Custom Routine/Task] ---> [SQLite Local Persistence (.data/streamlit_demo.sqlite)] ---> [Date-Aware Recurrence & Horizon Filtering] ---> [JSON Backup / Restore]
