Your friend LXNORO

Application Map, Architecture & Technical Specifications

1. Application Purpose & High-Level Architecture

Your friend LXNORO is a lightweight personal digital companion and Micro-Bot Time Engine designed to connect long-range personal planning horizons (from day to five years) with timely, actionable daily moments. It consolidates routines, scheduled tasks, expandable notes, Micro-Bot reminders, MET Norway weather context, and a privacy-conscious shared booking service into one cohesive web platform.

Local-First Client (React + Vite + Dexie)

Handles personal time matrices, multi-horizon navigation, activity/routine scheduling, substantial notes (up to 1,000 words), MET Norway weather preference/caching, in-app/browser notifications, and Firebase Google authentication state.

Privacy-Safe Booking Server (Fastify + SQLite)

Manages authenticated owner availability projection sync (interval-only, zero private task IDs/titles/notes), public availability queries, shared booking requests, owner approvals/rejections, alternative time proposals, and Nodemailer SMTP confirmation emails.

2. Actual Screens & Major UI Areas

  • Google Sign-In / Dark Login Screen: Renders a secure authentication barrier when signed out, featuring the brand lockup and a Continue with Google button powered by Firebase Auth (with fallback error handling if Firebase configuration is missing).
  • Topbar & Navigation: Displays the brand lockup, location chip, notification/reminder test triggers, booking management panel toggle, Sign Out button, and English/Arabic (LTR/RTL) language switchers.
  • Time Matrix & Horizon Selector: Horizontal timeline grid supporting daily, weekly, monthly, yearly, and five-year planning horizons with "Now" and "Next" indicators.
  • Weather Context Banner: Displays rounded-coordinate temperature, symbol, precipitation, attribution, and freshness status when weather is enabled and permission is granted.
  • Starter Activities & Custom Editor: Visible unscheduled starter templates and custom activity creators allowing emoji selection, title, date, time, duration, recurrence rules, and expandable notes.
  • Micro-Bot Reminder Dialog: Pops up when an activity is due, revealing its symbol, title, full notes, and completion/snooze actions.
  • Owner Booking Panel: Interface for managing booking links, reviewing pending requests, approving/rejecting, and proposing alternative slots.

3. Core User Flows

[Authentication Flow] [App Open] ---> [Check Firebase Auth State] ---> (Signed Out) ---> [Dark Login Screen + Continue with Google] ---> [Popup Sign-In] ---> [Signed In State] ---> (Signed In) ---> [Load Local Dexie DB & Preferences] ---> [Time Matrix UI] [Personal Time Planning Flow] [Time Matrix / Horizon View] ---> [Create/Schedule Activity or Routine] ---> [Set Date/Time/Recurrence/Notes] ---> [Dexie Local Persistence] ---> [Micro-Bot Reminder at Due Time] ---> [Complete / Postpone] [Shared Appointment Booking Flow] [Owner Sync Busy Intervals] ---> [Public Shareable Link] ---> [Requester Selects Slot] ---> [Pending Request Created in SQLite] ---> [Owner Approval / Alternative Proposal] ---> [Conflict Recheck & SQLite Confirmation] ---> [Nodemailer SMTP Email Sent]

5. Data Flow & Integrations

  • Local-First Storage: Personal schedules, routine definitions, notes, and preferences reside entirely on-device in IndexedDB (Dexie). No private task titles or notes ever leave the device.
  • Privacy-Safe Booking Projection: Scheduled activities produce anonymous, coalesced busy time intervals synchronized with the Fastify/SQLite booking backend solely for conflict detection.
  • Weather Integration: Optional location-based MET Norway Locationforecast 2.0 requests via the LXNORO proxy with coordinate rounding, local caching, and attribution.
  • Transactional Email: Nodemailer SMTP relay integration for booking confirmations and owner reminders.
